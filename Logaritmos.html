¿A qué exponente hay que elevar la base?

Eso es un logaritmo. Es la operación inversa de la potenciación y sirve para despejar exponentes, comparar magnitudes enormes y resolver ecuaciones que el álgebra común no alcanza.

Calculadora de logaritmos

Definición

El logaritmo de x en base b es el exponente y que cumple by = x. Las dos formas dicen lo mismo, y saber pasar de una a otra es la habilidad central del tema.

logb(x) = y  ⟺  by = x

Para que tenga sentido se exige b > 0, b ≠ 1 y x > 0. No existe el logaritmo de cero ni de un número negativo, porque ninguna potencia positiva da ese resultado.

Dos bases con nombre propio

Logaritmo común: log(x) significa base 10. Logaritmo natural: ln(x) significa base e ≈ 2,71828, el número que aparece en el crecimiento continuo.

Propiedades

Los logaritmos convierten productos en sumas y potencias en productos. Con ellas se simplifica casi cualquier expresión. Todas valen para M, N > 0.

Producto
logb(M·N) = logbM + logbNMultiplicar dentro equivale a sumar fuera.
Cociente
logb(M/N) = logbM − logbNDividir dentro equivale a restar fuera.
Potencia
logb(Mk) = k·logbMEl exponente baja y multiplica. Con ella se despejan incógnitas en el exponente.
Cambio de base
logbx = log x / log b = ln x / ln bPermite calcular cualquier base con una calculadora que solo tiene log y ln.
Identidades
logb1 = 0   logbb = 1   blogbx = xCualquier base elevada a 0 da 1, y elevada a 1 da la misma base.

Ecuaciones resueltas

Ecuación logarítmica con dos términos

log2(x) + log2(x − 2) = 3
  1. Aplica la propiedad del producto: log2[x(x − 2)] = 3.
  2. Pasa a forma exponencial: x(x − 2) = 23 = 8.
  3. Ordena: x² − 2x − 8 = 0, que factoriza como (x − 4)(x + 2) = 0.
  4. Verifica el dominio (x > 2): x = −2 no sirve. Solución: x = 4.

Incógnita en el exponente

3x = 20
  1. Aplica log a ambos lados: log(3x) = log 20.
  2. Baja el exponente: x·log 3 = log 20.
  3. Despeja: x = log 20 / log 3 ≈ 1,3010 / 0,4771. Solución: x ≈ 2,727.

Diferencia de logaritmos

log(x + 1) − log(x − 1) = 1
  1. Aplica la propiedad del cociente: log[(x + 1)/(x − 1)] = 1.
  2. Forma exponencial en base 10: (x + 1)/(x − 1) = 10.
  3. Resuelve: x + 1 = 10x − 10, así que 9x = 11.
  4. Verifica el dominio (x > 1): 11/9 cumple. Solución: x = 11/9 ≈ 1,222.

Dónde se usan

Las escalas logarítmicas aparecen cuando los datos abarcan muchos órdenes de magnitud.

Acidez (pH)

pH = −log[H⁺]. Bajar una unidad de pH significa diez veces más iones de hidrógeno.

Sonido (decibelios)

dB = 10·log(I/I₀). Cada 10 dB la intensidad se multiplica por diez.

Sismos (Richter)

Cada punto de magnitud equivale a una amplitud de onda diez veces mayor.

Finanzas

Para duplicar un capital al 5 % anual: t = ln 2 / ln 1,05 ≈ 14,2 años.

Errores frecuentes

  • log(M + N) no es log M + log N. La suma solo aparece cuando se multiplica por dentro.
  • log M / log N no es log(M/N). Ese cociente es un cambio de base.
  • (log M)k no es k·log M. La propiedad de la potencia afecta al argumento, no al logaritmo completo.
  • Olvidar verificar el dominio: toda solución debe dejar positivos los argumentos originales.
